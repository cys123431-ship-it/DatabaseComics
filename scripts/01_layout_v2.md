원본 근거: 강의 PDF 1~2쪽. 만화 01/24 — 프롤로그.
학습 목표: 제2장 제목과 네 개 목차를 정확히 소개한다. E. F. Codd, System R, SQL 예제, STUDENT/ENROLL/COURSE 테이블은 02페이지 이후에만 사용한다.

## 정확히 5컷 — 컷 수 초과 금지
1. 상단 가로 컷, 도서관 복도: 흑갈색 소녀가 ‘2장. 관계 데이터 모델과 제약조건’ 책을 들고 있다.
   - 흑갈색: “관계 데이터 모델과 제약조건… 제목부터 어렵네.”
   - 카리나: “데이터베이스 공부하는 거야?”
2. 왼쪽 중간 컷, 도서관 책상: 카리나가 장난스럽게 팔짱을 끼고, 흑갈색 소녀는 반박한다.
   - 카리나: “표로 정리하는 건 알지?”
   - 흑갈색: “그걸 데이터베이스에서 어떻게 쓰는지가 궁금해!”
3. 오른쪽 중간 컷, 책의 목차를 크게 보여 주는 장면: 두 소녀의 손과 책 중심.
   - 흑갈색: “배울 게 네 가지나 있네?”
   - 카리나: “하나씩 알아보자.”
   - 책 안에 정확한 네 줄:
     - 2.1 관계 데이터 모델의 개념
     - 2.2 릴레이션의 특성
     - 2.3 릴레이션의 키
     - 2.4 무결성 제약조건
4. 하단 왼쪽 컷, 상상 속 데이터 공간: 떠다니는 빈 표와 자물쇠. 예시 SQL과 실제 데이터 값, 새로운 용어를 넣지 않는다.
   - 카리나: “데이터를 표현하고 지키는 규칙을 배워.”
   - 흑갈색: “구조와 규칙을 함께 배우는 거구나!”
5. 하단 오른쪽 컷, 도서관 책상: 흑갈색 소녀가 펜을 들고 질문한다. 카리나는 책장을 넘긴다.
   - 흑갈색: “그 모델은 누가 만들었어?”
   - 카리나: “좋아. 1970년으로 가 보자!”

## 레이아웃 필수 조건
- 만화 한 페이지 단 하나의 세로 이미지, 5개의 독립적이고 경계가 분명한 컷.
- 컷 1은 가로로 넓게, 컷 2·3은 좌우로 나란히, 컷 4·5도 좌우로 나란히. 1+2+2=5.
- 각 컷의 대사는 위의 두 문장만, 문구 추가·중복·변형 금지. 인물별 말풍선 연결을 확인한다.
- 제목과 목차만 원본 PDF의 정확한 사실 정보다. 그 밖의 대화와 상상 장면은 교육용 각색이다.
- 사용자 제공 캐릭터 외형·의상·색감을 유지: 카리나=긴 백금발, 회색 눈, 초록/흰 목도리, 회색 조끼, 검은 망토; 학습자=긴 흑갈색 웨이브, 갈색 눈, 붉은 넥타이, 회색 조끼, 검은 망토.
- 출판 합격 기준: 정확히 5컷, 목차 네 줄 정확, 두 인물 일관, 한국어 말풍선 오탈자 없음, PDF 1~2쪽 외 개념 설명 없음.

참고: scripts/01.md는 장면 설명과 장편 대사를 담은 원본 대본이며, 이 파일은 실제 한 페이지 이미지 가독성을 위해 대사를 압축한 제작용 버전이다.
