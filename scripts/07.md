# 07. 같은 표, 다른 이름 — 그리고 NULL의 비밀 (1차 초안)

- **만화 페이지:** 07/24 (독립 세로형 컬러 만화 1장)
- **강의 PDF 근거:** 『2장. 관계 데이터 모델과 제약조건』 PDF **14~15쪽**
- **원문 근거:** PDF 14쪽 [표2.2] 용어들의 대응관계. PDF 15쪽 널(NULL)의 의미, 0·공백과의 구별, DBMS별 표시 기호 차이.
- **학습 목표:** (1) 릴레이션/투플/애트리뷰트의 공식·일상·파일시스템 용어를 대응한다. (2) NULL은 '알려지지 않음' 또는 '적용할 수 없음'을 나타내며 숫자 0·공백과 구별함을 이해한다.
- **사실·창작 구분:** 용어 대응과 NULL 설명은 PDF에 근거. '마법 도서관', 인물 대화, 신입 사원 예시의 인물·사원번호는 연출을 위한 창작이다. 창작 예시를 강의자료 원문 표라고 소개하지 않는다.

## 고정 등장인물
- **카리나(설명):** 오른쪽 백금발, 차가운 하얀 피부, 회색 눈, 초록·흰색 줄무늬 목도리, 회색 조끼, 검은 망토. 단정하고 직설적인 말투.
- **학습자:** 왼쪽 긴 흑갈색 웨이브 머리, 갈색 눈, 붉은 넥타이, 회색 조끼, 검은 망토. 표정과 행동이 풍부함.
- **남성 등장 금지.** 다른 페이지의 기존 여성·남성 조합을 사용하지 않는다.

## 컷별 정확한 대본 — 5컷

### 1컷 (상단 넓은 컷: 도서관의 세 갈래 문)
- **장면:** 고풍스러운 마법 도서관, 하나의 빛나는 데이터 표가 '공식 용어', '자주 쓰는 용어', '파일 시스템' 세 개의 문 앞에 복제되어 나타난다. 학습자가 서로 다른 간판을 보며 혼란스러워한다. 카리나는 미소를 지으며 마법 지팡이로 문을 연다.
- **학습자:** “똑같은 표인데 이름이 왜 세 가지나 있어?”
- **카리나:** “표현하는 대상은 같아. 부르는 분야에 따라 용어가 달라질 뿐이지.”

### 2컷 (가장 큰 중앙 컷: 세 칸이 나란히 열린 마법 서랍)
- **장면:** 카리나가 서랍을 열면 세 열이 있는 정확한 용어 대응표가 공중에 펼쳐진다. 학습자가 각 행을 손가락으로 짚는다. 표는 **독자가 정확히 읽을 수 있도록 크게**.
- **카리나:** “이 대응표만 기억하면 용어가 바뀌어도 헷갈리지 않아.”
- **학습자:** “아! 릴레이션이 테이블이고, 파일 시스템에서는 파일이구나!”
- **필수 표:**

| 공식적인 용어 | 자주 사용되는 용어 | 파일 시스템의 용어 |
|---|---|---|
| 릴레이션 | 테이블 | 파일 |
| 투플 | 행/레코드 | 레코드 |
| 애트리뷰트 | 컬럼/속성/열 | 필드 |

### 3컷 (좌측 기울어진 액션 컷: 실제 표 위를 뛰어넘기)
- **장면:** EMPLOYEE라는 표 위에서 학습자가 가로 한 행을 빛나는 띠처럼 잡아당긴다. 카리나는 세로 열을 깃펜으로 가리킨다. 표 내용은 최소한으로: `EMPNO | EMPNAME | DNO` / `2106 | 김창섭 | 2`. (이 행은 PDF 18쪽의 기존 사원 예시에서 일부 열만 발췌한 보조 시각화이며, PDF 14~15쪽 원문 그림이라고 표시하지 않는다.)
- **학습자:** “한 행은 투플, 한 열은 애트리뷰트!”
- **카리나:** “맞아. 레코드와 필드라는 말도 함께 알아 둬.”

### 4컷 (우측 어두운 분위기의 컷: 신입사원 카드에 빈 부서 칸)
- **장면:** 신입사원 카드 `EMPNO: 5010 / EMPNAME: 신입사원 / DNO: NULL`이 떠 있고, DNO 칸에는 물음표 모양 안개가 낀다. **'설명을 위한 창작 예시'**라는 작은 캡션을 둔다.
- **학습자:** “부서번호가 아직 정해지지 않았다면?”
- **카리나:** “그럴 땐 NULL을 써. ‘알려지지 않음’이나 ‘적용할 수 없음’을 나타내지.”

### 5컷 (하단 넓은 클로징 컷: 세 개의 유리병 비교)
- **장면:** 학습자가 0, 공백 문자열, NULL 세 유리병을 나란히 들고 혼동한다. 카리나가 0과 공백을 한쪽, NULL을 다른 쪽으로 나누어 설명한다. 화면에 세 개의 라벨이 명확히 보인다: `0 = 숫자값`, `' ' = 공백 문자`, `NULL = 알려지지 않음/적용할 수 없음`. 'DBMS마다 NULL 표시 기호는 다를 수 있음' 보조 문구.
- **학습자:** “NULL이 0이나 공백이랑 같은 건 아니구나!”
- **카리나:** “정확해. 값 0과 공백은 NULL과 달라.”
- **예고:** “다음 08. 릴레이션 스키마와 인스턴스”
