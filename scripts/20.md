# 20/24 — 참조 무결성 제약조건

원본 PDF 41~42쪽 근거. 6컷 대본은 로컬 /mnt/data/DatabaseComics/scripts/20.md에 작성됨.

1. EMPLOYEE.DNO는 DEPARTMENT.DEPTNO를 참조한다.
2. 외래 키 값은 참조된 기본 키 값과 일치하거나, 기본 키 일부가 아니고 NULL이 허용되는 경우 NULL이다.
3. 없는 DEPTNO를 참조하는 DNO는 허용되지 않는다.
4. 삽입·삭제·수정 시 DBMS가 참조 무결성을 확인해야 한다.
5. DEPARTMENT는 참조된 릴레이션, EMPLOYEE는 참조하는 릴레이션이다.
