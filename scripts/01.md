# 01. 관계 데이터 모델과 제약조건 — 프롤로그

원본 PDF: 1~2쪽. 목표: 두 주인공을 소개하고 네 개 학습 주제를 안내한다. 세로형 컬러 만화 1장, 5컷.

고정 인물: 카리나(백금발, 회색 눈, 초록·흰색 줄무늬 목도리, 회색 조끼, 검은 망토); 학습자(긴 흑갈색 웨이브 머리, 갈색 눈, 붉은 넥타이, 회색 조끼, 검은 망토). 제공된 이미지 외형·색감 준수.

## CUT 1. 이상한 책
장면: 오래된 도서관 복도. 흑갈색 소녀가 책을 들고 카리나가 들여다본다.
- 흑갈색: “관계 데이터 모델과 제약조건…? 제목부터 어렵네.”
- 카리나: “뭐야, 데이터베이스 공부하는 거야?”
- 흑갈색: “응. 그런데 관계라는 말부터 무슨 뜻인지 모르겠어.”
화면: 책 제목 ‘2장. 관계 데이터 모델과 제약조건’.

## CUT 2. 도발
장면: 도서관 책상. 카리나는 팔짱을 끼고 자신만만하게 웃는다. 흑갈색 소녀는 못마땅해한다.
- 카리나: “설마 데이터를 표로 정리하는 것도 어렵다고 하는 건 아니겠지?”
- 흑갈색: “표 정도는 알아! 하지만 데이터베이스에서 그걸 어떻게 사용하는지가 궁금한 거라고.”
- 카리나: “흐응, 그럼 제대로 알아보자고.”

## CUT 3. 네 가지 주제
장면: 펼쳐진 책을 위에서 내려다본다. 흑갈색 소녀가 목차를 읽는다.
- 흑갈색: “관계 데이터 모델의 개념, 릴레이션의 특성, 릴레이션의 키, 무결성 제약조건…”
- 카리나: “이번 장은 크게 그 네 가지야.”
- 흑갈색: “릴레이션의 키? 무결성? 모르는 용어가 잔뜩인데?”
책 목차: ‘2.1 관계 데이터 모델의 개념 / 2.2 릴레이션의 특성 / 2.3 릴레이션의 키 / 2.4 무결성 제약조건’.

## CUT 4. 상상 속 데이터 공간
장면: 두 소녀가 작게 보이는 거대한 가상 공간. 공중에 행·열 테이블과 규칙을 상징하는 자물쇠.
- 카리나: “일단 데이터를 어떻게 표현하고, 어떤 규칙으로 관리하는지부터 배우는 거야.”
- 흑갈색: “그러니까 데이터를 저장하는 방법뿐 아니라, 데이터가 잘못되지 않도록 하는 규칙도 배우는 거네?”
- 카리나: “맞아. 이제 좀 감이 오지?”

## CUT 5. 수업 시작
장면: 도서관 책상. 흑갈색 소녀는 진지하게 책을 펼치고 카리나는 펜을 든다.
- 흑갈색: “좋아. 대신 모르는 부분은 그냥 넘어가지 않을 거야.”
- 카리나: “누가 말렸어? 이해할 때까지 해보자고!”
- 흑갈색: “그럼 첫 번째 질문. 관계 데이터 모델은 누가 만든 거야?”
- 카리나: “좋은 질문이네. 1970년으로 돌아가 보자!”
