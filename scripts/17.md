# 17/24 — 외래 키의 두 유형: 자체 참조와 복합 기본 키 구성요소

원본 PDF 「2장. 관계 데이터 모델과 제약조건 (1)(1).pdf」 35~36쪽, 그림 2.12~2.13. 상세 대본 원본은 이번 회차 로컬 scripts/17.md에 작성됨.

6컷:
1. 학습자: “외래 키는 꼭 다른 표를 가리켜야 해?” 카리나: “아니. 같은 릴레이션의 기본 키를 참조할 수도 있어.”
2. 카리나가 원본 EMPLOYEE 표를 펼친다. 카리나: “MANAGER는 같은 EMPLOYEE의 EMPNO를 참조해.” 학습자: “MANAGER도 사번이네!”
3. 학습자가 2106→3426→3011을 따라간다. 학습자: “김창섭의 관리자는 박영권, 박영권의 관리자는 이수민이구나!” 카리나: “맞아. 같은 표 안에서 이어져.”
4. 학생·수강·과목 세 장부 등장. 학습자: “수강에는 외래 키가 두 개?” 카리나: “학번은 학생.학번, 과목번호는 과목.과목번호를 참조해.”
5. 원본 수강 네 행을 정확히 표시. 학습자: “11002도 CS310도 중복되는데?” 카리나: “각각 외래 키지만, (학번,과목번호)를 합쳐 기본 키야.”
6. 두 열의 빛나는 열쇠가 합쳐진다. 학습자: “자기 참조도, 복합 키 구성도 가능하구나!” 카리나: “참조 대상과 기본 키 구성을 구별해.”
