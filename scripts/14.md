# 14/24 — 후보 키에서 기본 키 선정

원본: 「2장. 관계 데이터 모델과 제약조건 (1)(1).pdf」 29~30쪽.
학습 목표: 후보 키 중 기본 키 하나 선정, 기본 키 선정의 다섯 고려사항 이해.

1컷 학습자: “후보 키가 둘이면, 둘 다 기본 키인가요?” 카리나: “아니. 후보 키 중 하나만 기본 키로 선정해.”
2컷 카리나: “카드사 고객 릴레이션에서 신용카드번호와 주민등록번호가 후보 키일 수 있어.” 학습자: “그럼 어떤 것을 고르죠?”
3컷 카리나: “원본 예시에서는 신용카드번호를 기본 키로 선정했어.” 학습자: “선정은 설계자나 관리자가 하는 거군요!”
4컷 카리나: “첫째, 값이 항상 고유해야 해. 둘째, NULL이 되지 않아야 해.” 학습자: “중복이나 빈 값이 생기면 안 되겠네요!”
5컷 카리나: “셋째, 값이 자주 바뀌는 속성은 피하고, 넷째, 작은 정수나 짧은 문자열을 선호해.” 학습자: “안정적이고 간결한 키가 좋겠군요.”
6컷 카리나: “다섯째, 가능하면 복합 기본 키를 피해. 단, 필요한 경우에는 복합 키도 쓸 수 있어.” 학습자: “후보 키에서 하나를 고르되, 고유성·NULL·변경·길이·복합 여부를 따지는 거네요!”

상세 연출 및 검수 기준은 로컬 scripts/14.md에 보존. 등장인물은 카리나와 여성 학습자 둘뿐. 실제 주민등록번호/카드번호 숫자 생성 금지. 31쪽 대리 키와 32쪽 대체 키는 제외.
