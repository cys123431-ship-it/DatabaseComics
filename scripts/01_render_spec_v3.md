# 01페이지 제작 사양 v3

원본 PDF 1쪽: 2장. 관계 데이터 모델과 제약조건. PDF 2쪽 목차: 2.1 관계 데이터 모델의 개념 / 2.2 릴레이션의 특성 / 2.3 릴레이션의 키 / 2.4 무결성 제약조건.

총 5컷, 세로형 1+2+2. 컷 1 도서관 복도 책 표지 읽기. 컷 2 책상에서 표에 관해 논쟁. 컷 3 책의 정확한 목차 네 줄 확인. 컷 4 상상 속 빈 표와 자물쇠. 컷 5 책상으로 돌아와 1970년으로 넘어가는 질문.

카리나: 백금발, 회색 눈, 녹백 줄무늬 목도리, 회색 조끼, 검은 망토. 학습자: 흑갈색 웨이브, 갈색 눈, 붉은 넥타이, 회색 조끼, 검은 망토. 원본 캐릭터 외형 고정.

그림은 독립된 5컷 만화로 만들고 말풍선은 별도 한국어 식자하여 오탈자를 방지한다. 컷별 대사는 scripts/01_layout_v2.md를 그대로 사용한다. 완성 이미지가 GitHub에 검증되기 전에는 0/24 유지.
