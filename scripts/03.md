# 03. 관계 데이터 모델의 장점 — 1차 초안
원본: 『2장. 관계 데이터 모델과 제약조건』 PDF 5~6쪽.
학습 목표: 단순한 릴레이션, 집합 처리, 선언적 질의 WHAT/HOW, 레코드 순서 독립성, 논리적 연결에 명시적 링크·포인터 불필요.

## 컷 1: 복잡한 서류 미로
학습자(서류 더미에서 길을 잃음): “데이터가 이렇게 얽혀 있으면 찾기 힘들잖아!”
카리나(팔짱): “그래서 단순한 구조가 강점이야.”

## 컷 2: 반듯한 테이블
카리나(서류를 표로 정리): “관계 데이터 모델은 데이터를 릴레이션, 즉 표로 표현해.”
학습자(표를 가리킴): “행과 열로 보니까 이해하기 쉽네!”
창작 예시 표: 학번 | 이름 / 1001 | 지민 / 1002 | 서연.

## 컷 3: 카드 묶음
학습자(레코드 카드를 하나씩 넘김): “하나씩 찾아야 해?”
카리나(카드 여러 장을 들어 올림): “아니, 레코드의 집합을 한 번에 처리할 수 있어.”
문구: 집합 단위 처리.

## 컷 4: 원하는 것과 찾는 방법
학습자(요청서 들고): “원하는 데이터만 말하면 돼?”
카리나(빛나는 표 옆): “맞아. SQL 같은 선언적 질의어는 ‘무엇을’ 원하는지 적어. ‘어떻게’ 찾을지는 일일이 지시하지 않아.”
문구: WHAT=원하는 데이터, HOW=찾는 절차.

## 컷 5: 다음 수업으로
학습자(실뭉치를 치움): “논리적 연결을 위해 포인터를 직접 따라갈 필요도 없겠네!”
카리나(다음 문을 엶): “맞아. 레코드 순서에 얽매일 필요도 없어.”
다음: 릴레이션의 행과 열.

고정 등장인물: 여성 둘만. 카리나(백금발·회색 눈·초록/흰 목도리·회색 조끼·검은 망토), 학습자(흑갈색 웨이브·갈색 눈·붉은 넥타이·회색 조끼·검은 망토).
교재 사실: PDF 5~6쪽의 개념. 서류 미로·마법·예시 학생 데이터는 만화적 창작. 물리적 저장에서 포인터가 절대 없다는 주장은 하지 않는다.
상태: 1차 시나리오 초안. 이미지는 별도 생성/게시 확인.
