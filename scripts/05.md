# 05. 도메인(domain) — 1차 초안

근거: 강의 PDF 10~11쪽. 도메인은 한 애트리뷰트에 나타날 수 있는 값들의 집합이며, 각 값은 원자값이다.

컷 1: 학습자가 값의 보관실에 들어가며 묻는다. 학습자: “표의 칸에는 어떤 값이 들어갈 수 있어?” 카리나: “각 속성에는 가능한 값들의 범위가 있어.”

컷 2: 카리나가 EMPNAME 값들의 구체를 보여준다. 카리나: “이렇게 가능한 값들의 집합을 도메인이라고 해.” 구체: 김창섭, 박영권, 이수민, 조민희, 김동수, 안영석, … . 학습자: “표에 아직 없는 이름도 있네?” 카리나: “현재 저장된 값만 뜻하는 건 아니야.”

컷 3: 학습자가 한 칸에 여러 이름표를 쌓는다. 카리나: “각 애트리뷰트의 값은 원자값이야.” 라벨: 한 칸 → 원자값 하나.

컷 4: 칠판 앞에서 카리나가 설명한다. 카리나: “도메인은 프로그래밍 언어의 데이터 타입과 비슷해.” 칠판: CREATE DOMAIN EMPNAME CHAR(20) / CREATE DOMAIN EMPNO INTEGER / CREATE DOMAIN DNO INTEGER. 학습자: “문자와 정수처럼 정의하는 거구나!”

컷 5: 같은 빛의 도메인이 서로 다른 두 열에 연결된다. 학습자: “같은 도메인을 여러 속성에서 쓸 수도 있어?” 카리나: “그렇지!” 예고: 06. 차수와 카디날리티.

인물은 두 여성만: 백금발 회색 눈 초록/흰 목도리의 카리나, 흑갈색 웨이브 갈색 눈 붉은 넥타이의 학습자. 세로 컬러 만화 한 장. 창작 연출은 강의 사실과 구별한다. 상태: 대본 초안, 이미지 별도 생성 예정.
