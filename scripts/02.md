# 02. 1970년, 관계 데이터 모델의 탄생 — 1차 전체 초안

- **만화 페이지:** 02/24 (01페이지 프롤로그 다음 장면)
- **강의 PDF 근거:** 3쪽(관계 모델의 제안과 System R, 보급), 4쪽(관계 DBMS 제품 예시)
- **학습 목표:** ① E. F. Codd가 IBM 연구소에서 1970년에 관계 데이터 모델을 제안했다는 사실 이해 ② System R이 1970년대 IBM 연구소에서 개발된 중요한 관계 DBMS 시제품임을 구별 ③ 오늘날 여러 관계 DBMS 제품이 사용됨을 인식
- **주의:** 'Codd가 System R을 직접 개발했다'거나 'System R이 세계 최초의 모든 관계 DBMS였다'고 말하지 않는다. 교재는 System R을 '관계 데이터 모델을 최초로 구현한 가장 중요한 관계 DBMS 시제품'이라고 소개한다. 강의 사실과 만화적 상상 장면을 구별한다.
- **고정 인물:** 카리나(차가운 백금발·회색 눈·초록/흰색 줄무늬 목도리·회색 조끼·검은 망토), 학습자(긴 흑갈색 웨이브 머리·갈색 눈·회색 조끼·붉은 넥타이·검은 망토). 여성 둘만 등장. 이전 캐릭터로 바꾸지 않는다.
- **형식:** 세로형 독립 컬러 만화 1장, 5컷. 각 컷의 크기와 구도를 다르게. 컷 번호 1~5가 아닌 만화 장면의 흐름으로 자연스럽게 읽히게.

## CUT 1 — 도서관의 시간 문 (넓은 상단 컷)
**배경/동작:** 01페이지의 마법 도서관. 카리나가 책장을 휙 넘기자 황금빛 시계와 1970 숫자가 떠오르고, 학습자는 망토를 붙잡고 뒤로 젖힌다. 로우앵글, 책장 소용돌이.
- 학습자: “1970년? 갑자기 시간 여행이야?!”
- 카리나: “관계 데이터 모델이 시작된 때부터 보자.”
- **글자:** 시간 소용돌이에 “1970”.

## CUT 2 — IBM 연구소의 칠판 (중간 왼쪽 컷)
**배경/동작:** 복고풍 연구실을 내려다보는 두 여성. 사람의 실물 초상은 그리지 말고, 칠판과 기록 카드만 클로즈업. 카리나는 칠판의 이름과 연도를 가리킨다.
- 카리나: “IBM 연구소의 E. F. Codd가 1970년에 관계 데이터 모델을 제안했어.”
- 학습자: “생각보다 오래된 개념이네!”
- **칠판:** “E. F. Codd / 1970 / 관계 데이터 모델”.

## CUT 3 — 거대한 컴퓨터실 (중간 오른쪽 컷)
**배경/동작:** 1970년대 대형 컴퓨터 장비와 펀치카드가 늘어선 실험실. 학습자가 거대한 장비를 올려다보며 놀라고, 카리나가 System R이라고 적힌 연구 기록을 펼친다.
- 학습자: “이 커다란 장비들은 뭐야?”
- 카리나: “1970년대 IBM 연구소에서는 중요한 관계 DBMS 시제품 ‘System R’을 개발했지.”
- **기록 카드:** “System R — 1970년대 / 관계 DBMS 시제품”.

## CUT 4 — 현재로 복귀, 제품 이름의 거리 (하단 왼쪽 컷)
**배경/동작:** 시계가 빠르게 돌아 현대의 도서관으로 변한다. 허공에 작은 명패가 차례로 등장. 학습자가 이름을 손가락으로 세고 카리나는 웃는다.
- 학습자: “그럼 지금도 관계 DBMS를 많이 써?”
- 카리나: “그럼. 여러 제품이 널리 쓰여.”
- **명패:** “Oracle”, “SQL Server”, “MySQL”, “PostgreSQL”, “DB2”, “MS Access”. 교재 4쪽에 있는 제품명 예시일 뿐 현재 점유율이나 순위를 주장하지 않는다.

## CUT 5 — 다음 수업의 문 (하단 가로 큰 컷)
**배경/동작:** 도서관 탁자에 평범한 종이 표가 나타난다. 학습자는 손가락으로 표의 한 칸을 짚고, 카리나는 펜으로 행과 열을 가리킨다. 시간여행의 잔광이 사라진다.
- 학습자: “그런데 ‘관계’라는 말은 아직 어렵네.”
- 카리나: “다음엔 가장 기본인 ‘릴레이션’을 표로 살펴보자.”
- **표 머리글:** “학번 | 이름 | 학과” (설명을 위한 창작 예시. PDF 원문 표라고 주장하지 않음.)
- **하단 연결 문구:** “다음: 관계 데이터 모델의 개념”
